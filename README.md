# AI 同事系統(AI Colleague OS)— Pitch Demo(`/demo`)

一套以「AI 同事」為核心的中小企業營運系統 **展示版**:AI 自動處理有數據的工作並附上建議,人類只負責決策,每次決策回饋讓 AI 持續學習。

> 這是拿去給老闆看的 **pitch demo**:全程使用模擬資料、零外部服務,`npm install && npm run dev` 即可在本機跑起來,對方可自己接手操作。

## 快速開始

```bash
npm install
npm run dev
# 開啟 http://localhost:3000 — 首頁為個人網站
# Demo 入口:http://localhost:3000/demo
```

不需要任何金鑰或設定。所有 AI、LINE、Email、資料庫皆為本機 mock。

## Demo 怎麼演(脊椎:AI 決策佇列)

1. 預設以「老闆 / 電動機車廠」進入 **決策佇列**,看到「AI 今天完成 13 件 · 待你決策 5 件」。
2. 一張張決策卡:每張都有 **情境 + AI 建議 + 判斷理由 + 影響範圍**,底部三鍵 **採納 / 調整 / 駁回**。
3. **第一個哇** — 採納一張卡,它會飛走;5 分鐘滑完全公司決策。
4. **第二個哇(學習迴圈)** — 對「碳纖維前叉補貨」按 **調整 → 改補 50 支**,立即跳出「已學習:您偏好保留 15% 以上安全庫存緩衝」;往下捲,下一張「電池模組補貨」卡頂端就出現 **「已依您的偏好調整」** — AI 當場變懂你。
5. 右上角 **DemoBar** 一鍵切換:
   - **產業**(電動機車廠 / 3C 電商 / 中央廚房)→ 術語、流程站點、決策卡全變。
   - **角色**(老闆 / 主管 / 員工 / 客戶)→ 可見模組與金額欄位跟著變(員工看不到成本,只剩今日任務)。
   - **重置**:一鍵還原 demo 資料。

## 模組

| 模組 | 說明 |
|---|---|
| 決策佇列 | 系統脊椎:AI 建議集中決策 + 學習迴圈 |
| 儀表板 | 老闆營運總覽(營收/KPI/貢獻排行/AI 成長)、員工今日任務 |
| 訂單/工單追蹤 | 產業站點進度、手機推進、`/track/[單號]` 客戶自助查詢 |
| 進銷存 | 移動平均補貨建議、手機盤點 + AI 差異分析、廚房效期 |
| 報價引擎 | 3 秒試算成本/建議售價、寄出追蹤 |
| AI 客服 | 客戶對話(限自己訂單)、負面情緒轉真人 |
| AI 選品 | 電商專屬:趨勢爆品候選卡 |
| 產業雷達 | 新聞三段式(事實/影響/建議)進決策佇列 |
| 後台 | 產業設定、模組開關、欄位可見性、AI 成長報告 |

## 技術

- **Next.js 14 (App Router)** + **Tailwind** + 自製 shadcn 風元件 + **framer-motion**
- 手機優先 RWD、zh-TW、乾淨明亮專業視覺
- 記憶體 seed store(app 層 mock,取代 Supabase);輕量角色權限過濾(取代生產級 RLS)
- Mock AI provider(情境化罐頭 + 自由輸入優雅回應),介面保留未來換真 Claude 的簽名

## 專案結構

```
app/            # 頁面(route groups)+ API routes
modules/        # 各模組 service + components(獨立)
lib/
  data/         # 記憶體 store + 三產業 seed
  industry/     # 產業適配層(術語/站點/計價/開關)
  ai/           # AI provider(mock)
  auth/         # DemoBar + 角色權限
  ui/           # 共用元件
```

## 品質驗證

- 全 3 產業 × 4 角色 × 所有頁面瀏覽器巡檢:零 console/page error
- 互動流程自動測試(Playwright):決策採納/調整/學習反映、員工任務、工單推進、盤點差異、AI 客服 — 全數通過
